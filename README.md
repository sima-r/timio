# timio
TIME WELL SPENT

Using Streamlit, this app allows you to enter your daily time spent on various categories and save the data to a CSV file. You can also view the saved data in a table format.
The new entry will be appended to the CSV file. Make sure to reset the form before adding new entries at each attempt. 

Usage
1. Install the required packages:
   pip install streamlit pandas
2. Run the app:
   python -m streamlit run timio.py
